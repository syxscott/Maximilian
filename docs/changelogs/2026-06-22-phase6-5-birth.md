# Phase 6.5 — Agent Birth Engine

**Date**: 2026-06-22
**Status**: Completed

## What

`AgentBirthEngine.birth()` materializes a blueprint for a newly active capability.

## Implementation

`packages/meta-system/src/agent-birth.ts`:

- Derives `role = ${capabilityId}_agent` (deterministic)
- Composes a system prompt mentioning the role and discipline
- Calls optional `saveBlueprint(blueprint)` callback (consumer persists to BlueprintStore)
- Writes audit file to `<rootDir>/agent-births/<blueprintId>.json`

The `AgentBirthResult` schema captures the complete birth (id, role, systemPrompt, capabilities, constraints, parentCapability, createdAt).

## Decisions

- ADR-023: AgentBirth writes audit + optional blueprint callback

## Tests (5 unit tests)
