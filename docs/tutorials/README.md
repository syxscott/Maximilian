## Production notes

- **Resolution**: 1920×1080, 30 fps.
- **Audio**: 48 kHz mono, voice-over recorded separately and
  synchronized in post.
- **Captions**: SRT files generated automatically from script.
- **Format**: H.264 + AAC, target 8 Mbps for source.

## Tools needed

- Screen recorder (OBS Studio recommended).
- Terminal with a clean theme (Solarized Dark works well).
- Browser (Firefox or Chrome) at 1920×1080.
- Text editor with syntax highlighting.

## Voice-over style

- Friendly, direct. "We do X" not "Let me show you X".
- No marketing fluff. Skip adjectives.
- Show the failure mode, then the fix. Don't hide errors.
